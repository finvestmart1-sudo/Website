============================================================
  FINVESTMART - SETUP INSTRUCTIONS FOR HOSTINGER
  Complete in 10 minutes, no coding needed
============================================================

STEP 1 — Create MySQL Database
───────────────────────────────
1. Login to Hostinger hPanel (hpanel.hostinger.com)
2. Go to: Hosting → Manage → Databases → MySQL Databases
3. Click "Create database"
4. Note down:
   • Database name   (e.g.  u123456789_finvestmart)
   • Database user   (e.g.  u123456789_finuser)
   • Password        (the one you set)
   • Host            (usually: localhost)


STEP 2 — Import Database Tables
─────────────────────────────────
1. In Hostinger hPanel → Databases → phpMyAdmin
2. Click "Open phpMyAdmin"
3. Select your database on the LEFT panel
4. Click the "Import" tab at the top
5. Click "Choose File" → select:  database/finvestmart.sql
6. Scroll down → click "Go"
7. You should see "Import has been successfully finished"

This creates all tables and adds:
  • 2 test users   → email: rahul@example.com  / password: Test@1234
  • 1 admin user   → email: admin@finvestmart.com / password: Admin@123


STEP 3 — Update Database Credentials
──────────────────────────────────────
Open:  config/database.php

Change ONLY these 4 lines (lines 11-17):

  define('DB_HOST', 'localhost');           ← keep as localhost
  define('DB_USER', 'u123456789_finuser');  ← your DB username from Step 1
  define('DB_PASS', 'your_password');       ← your DB password from Step 1
  define('DB_NAME', 'u123456789_finvestmart'); ← your DB name from Step 1
  define('SITE_URL', 'https://yoursite.com');  ← your actual domain


STEP 4 — Upload Files to Hostinger
────────────────────────────────────
1. In Hostinger hPanel → File Manager
2. Open the "public_html" folder
3. Delete any existing files (index.html, etc.) if needed
4. Click "Upload" → select this ZIP file → Extract here
   OR upload all files/folders individually

Make sure these folders are INSIDE public_html:
  public_html/
    ├── index.html
    ├── login.html
    ├── register.html
    ├── dashboard.html
    ├── .htaccess
    ├── assets/
    ├── api/
    ├── admin/
    ├── config/
    ├── database/
    └── products/


STEP 5 — Test Your Website
────────────────────────────
1. Go to: yourdomain.com
   → Homepage should load ✓

2. Go to: yourdomain.com/login.html
   → Login with: rahul@example.com / Test@1234
   → Dashboard should open ✓

3. Go to: yourdomain.com/admin/login.php
   → Login with: admin@finvestmart.com / Admin@123
   → Admin panel should open ✓


STEP 6 — Change Default Passwords (Important!)
────────────────────────────────────────────────
⚠ Change these immediately after first login:

Admin password → Go to phpMyAdmin → users table → find admin@finvestmart.com
  → Edit → change password_hash using:
  SELECT PASSWORD_HASH('YourNewPassword', 'BCRYPT', 12);
  (Or use the Profile section in dashboard)

Test users → Delete rahul@example.com and priya@example.com
  from phpMyAdmin → users table → Delete row


OPTIONAL — Enable HTTPS
─────────────────────────
1. In Hostinger hPanel → SSL → Install (free Let's Encrypt)
2. After SSL is active, open .htaccess and:
   - Uncomment the HTTPS redirect lines (remove the # at start)
   - Uncomment:  php_value session.cookie_secure 1
